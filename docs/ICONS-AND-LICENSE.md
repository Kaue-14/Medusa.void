# Icons and license notes

The language icons displayed in the README are the original **Devicon** images
chosen by the project author. They are referenced without visual modifications.

For the Visual Studio Marketplace, the official `vsce` packager restricts external
SVG files to trusted badge providers. Devicon SVG images on jsDelivr may fail this
check; convert the **original Devicon SVGs** faithfully to PNG for the Marketplace
variant of README. Do not substitute the code-file icons or any different art.

This theme also contains inherited syntax token rules licensed under MIT.
The inherited rule set is now self-contained under `src/compatibility-token-colors.json`,
so the build does not depend on a separate vendor theme.
The upstream copyright and license notice in `LICENSE` and `THIRD_PARTY_NOTICES.md`
**must remain** until the inherited rules are independently rewritten or removed.
Removing the trademark from marketing text does not remove license obligations.
