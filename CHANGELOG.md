# Changelog

All notable changes to **Medusa.void** will be documented here.

## [1.0.1] - 2026-10-16

### Release

- Branded the extension and its single color theme as **Medusa.void**.
- Included the original pixel-art calico cat as the extension icon.
- Provided a unified near-black OLED interface, pastel syntax highlighting, and subtle guide colors.
- Added the HTML attribute syntax refinements and preserved highlighting for other languages.
- Coordinated terminal ANSI colors, editor widgets, menus, search, and Git/diff highlights.
- Included English documentation, a color palette, and real VS Code syntax screenshots.
- Added optional visual settings and example files for testing.

The `1.0.1` release is distributed as a VSIX for local installation. Marketplace publication has not yet been performed.
